# 복구 가이드

## 앱이 열리지 않음

1. 현재 실습 폴더가 맞는지 확인합니다.
2. 터미널에서 `python app.py`를 실행합니다.
3. `ModuleNotFoundError: gradio`이면 상위 폴더에서 `pip install -r requirements.txt`를 한 번 실행합니다.
4. 표시된 `http://127.0.0.1:7860` 주소를 브라우저에서 엽니다.

## 포트가 사용 중임

이전 앱 터미널에서 `Ctrl+C`로 종료한 뒤 다음 실습을 실행합니다.

## 변경 후 오류

현재 실습 폴더에서:

```bash
python reset.py
```

을 실행합니다. 현재 실습만 초기화됩니다.

## 중단 규칙

5분 이상 막히면 해당 실습을 초기화하고 다음 독립 실습으로 이동합니다. 한 실습의 실패로 나머지를 막지 않습니다.
