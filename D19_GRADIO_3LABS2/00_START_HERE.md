# D19 Gradio RAG 3실습

오늘은 코드를 처음부터 만들지 않습니다. 완성된 Gradio 앱 세 개에서 변수 하나만 바꾸고 같은 질문으로 결과를 비교합니다.

## 공통 패턴

1. 처음 한 번만 `00_INSTALL_GRADIO_WITH_CONTINUE.md`를 열어 Continue로 Gradio 설치 여부를 확인합니다.
2. 실습 폴더를 하나만 엽니다.
3. `run_windows.bat`을 더블클릭합니다. Mac은 `run_mac.command`를 사용합니다.
4. 터미널에 나온 `http://127.0.0.1:7860` 주소를 엽니다.
5. 변경 전 질문을 실행하고 캡처합니다.
6. 안내된 파일에서 변수 하나만 바꿉니다.
7. 앱을 `Ctrl+C`로 끄고 다시 실행합니다.
8. 같은 질문을 다시 실행하고 캡처합니다.
9. 다음 실습은 반드시 별도 폴더에서 새로 시작합니다.

## 실습 순서

- `01_INDEXING_LAB`: FAQ를 추가하면 답할 수 있는 범위가 바뀝니다.
- `02_RETRIEVAL_LAB`: Top-k를 바꾸면 검색 근거가 바뀝니다.
- `03_GENERATION_LAB`: 답변 규칙을 바꾸면 말하는 방식이 바뀝니다.

## 막혔을 때

각 실습에서 `python reset.py`를 실행하면 해당 실습만 초기화됩니다. 다른 실습에는 영향이 없습니다.
